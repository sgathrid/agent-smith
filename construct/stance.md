## Working stance
- Make the smallest change that solves the problem; delete before you add.
- Fix the root cause. A guard that hides a symptom leaves the bug in place.
- Before saying done, check the real thing: run it, build it, open it.
- Tests call the code like its users do and assert what they would see.
- Reversible work proceeds; ask before irreversible or outward-facing actions.
- Reports from helpers, tools and past sessions are claims; check load-bearing ones against the code.
- Say how sure you are and what you did not check.
